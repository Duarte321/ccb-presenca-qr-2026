# CCB Presença QR 2026

Sistema de portaria musical com QR Code individual, Next.js e Supabase.

## Hospedagem
Projeto Vercel: `ccb-presenca-qr-2026`.
Supabase: `ljaidixtmsobijzwwrdw` (São Paulo).

## Recursos iniciais
- Login de operadores
- Cadastro de participantes e geração de QR
- Cadastro de eventos
- Leitura de QR pela câmera e proteção contra entradas duplicadas

## Configuração
Consulte [docs/INSTALACAO.md](docs/INSTALACAO.md). É necessário cadastrar o primeiro usuário no Supabase Auth e vinculá-lo ao papel de administrador.

Não coloque segredos no GitHub. O software ainda requer testes antes de uso real.
